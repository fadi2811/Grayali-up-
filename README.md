# Grayali up

Ton repas de midi, livré à ta salle.

Site en ligne : https://fadi2811.github.io/Grayali-up-/

- `index.html` : le site (réglages en haut du `<script>` : numéro WhatsApp, heure de fin des commandes, plats, boutique).
- `img/` : photos des plats.
- Stock, commandes et points : Google Apps Script (adresse `STOCK_URL`), géré avec le tableau de bord admin.

⚠️ Garde le même ordre des plats : le stock est lié à leur position (t0, t1… / d0, d1…).
